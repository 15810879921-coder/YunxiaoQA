# 口令面

```text
拉取测试任务：状态=待处理|处理中；[项目=…]
发起缺陷：标题=…；描述=…；[测试任务=ONEOS-xx | 交付=ONEOS-xx]；[负责人=…]；[证据=…]
发起缺陷(非本期)：标题=…；描述=…；负责人=…；[验证者=…]；[项目=…]
拉取待验缺陷：状态=已修复|暂不修复；[测试任务=…]；[负责人=…]
批量关闭已修复：[测试任务=…] 或 缺陷=ONEOS-a,ONEOS-b,…
再次打开：缺陷=ONEOS-xx；[原因=复现说明]；[证据=…]
并入当期迭代：缺陷=… 或 范围=已关闭且未挂迭代；迭代=（当期/指定名）
闭环测试任务：测试任务=ONEOS-xx
```

## 条线映射

| 条线 | 口令 |
|---|---|
| 1·A 知悉提测 | `拉取测试任务` |
| 1·B 测出 bug | `发起缺陷`（绑测试任务/交付） |
| 1·C 测试完成 | `闭环测试任务`（批量关闭后可自动检测并提示） |
| 2·1 非本期 bug | `发起缺陷(非本期)` |
| 2·3 回归闭环 | `拉取待验缺陷` + `批量关闭已修复` + `再次打开` + `并入当期迭代` |

## 口令细则

### 拉取测试任务

- 默认状态：`待处理` + `处理中`。
- 回报：编号、标题、状态、所属【交付】、计划开始、优先级/标签（若有）。
- 只读；可不进 Plan。

### 发起缺陷（本期）

- 必填：标题、描述（或可从证据生成描述后 Plan 回显）。
- 锚点：`测试任务=` 或 `交付=` 至少一个；缺则询问。
- 验证者：当前测试人（会话已知姓名；未知则 Plan 点选）。
- 负责人：同交付下【开发】任务负责人；多条开发任务 → Plan 字母表点选；口令显式 `负责人=` 优先。
- 必须走 SKILL「发起缺陷流水线」。

### 发起缺陷(非本期)

- 必填：标题、描述、`负责人=`。
- 验证者默认当前测试人；可口令覆盖。
- 不强制挂【测试】；有模块/页面信息则写入描述与标签。
- 同样强制诊断流水线。

### 拉取待验缺陷

- 默认状态：`已修复` + `暂不修复`。
- 可按测试任务 / 负责人过滤。
- 只读；可不进 Plan。

### 状态名注意（01_ONEOS）

- 缺陷「新建/打开」统一写 **待确认**（id=`28`）；**禁止**用「待处理」指缺陷。
- 「待处理」仅用于【测试】等**任务**（id=`100005`）。
- 「暂不修复」实网存在（id=`31`）；工作流可从待确认/再次打开迁入。

### 批量关闭已修复

- 仅处理状态=`已修复` 的缺陷 → `已关闭`。
- 口令给编号列表，或给 `测试任务=` 扫其关联已修复单。
- **跳过**测试已口头确认仍复现、或已执行 `再次打开` 的单。
- 写操作 → 必须 Plan。

### 再次打开

- 仅允许：当前状态=`已修复` → `再次打开`。
- 触发：回归时原路径仍复现。
- 必填复现说明（`原因=` 或描述追加「复测记录」）；有证据则附上。
- 负责人、验证者默认不改。
- 对 `待确认`/`再次打开`：禁止重复打开。
- 对 `暂不修复`：默认拒绝；用户在 Plan 显式确认「坚持再次打开」才可。
- 写操作 → 必须 Plan。

### 并入当期迭代

- 仅 `已关闭` 缺陷。
- `迭代=` 当期（按项目默认前缀下进行中迭代）或指定名称；**禁止本 Skill 创建迭代**。
- 写操作 → 必须 Plan。

### 闭环测试任务

- 校验该【测试】关联缺陷全部状态 ∈ {`暂不修复`, `已关闭`}。
- 通过则【测试】→ `已完成`；否则回报未闭环缺陷列表，停止。
- 写操作 → 必须 Plan。

## 编号与查重

- 优先显式 `ONEOS-xx`；禁止按标题猜编号后静默写。
- 发起前查重：同模块 + 同症状 + 同交付/需求 → 提示更新旧单。
